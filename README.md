# 老脸 · 抖音博主研究双 Skill

版本：1.0.0 · 2026-10-11

| 技能 | 核心问题 | 输入 | 主要成果 |
|---|---|---|---|
| laolian-douyin-benchmark | 哪些作品值得学、为何表现突出？ | 主页、作品链接、博主名单或公开作品清单 | 互动数据表、同账号表现对比、内容机制、公开商业路径、复用建议 |
| laolian-douyin-distill | 这个博主的方法如何学到手？ | 主页、指定作品范围或本地视频与语料 | 批量视频、全文转写、逐条拆解、账号方法、标题/开头/文案/转化模板 |

## 安装

两个仓库可分别安装。通过 GitHub 的 Code → Download ZIP 下载并解压，将解压目录重命名为对应 Skill 名称。解压后，把同名文件夹放入 Codex 的技能目录：默认是用户目录下 `.codex/skills/`。确认层级为 `skills/laolian-douyin-benchmark/SKILL.md` 或 `skills/laolian-douyin-distill/SKILL.md`，不要套两层同名目录。在新会话里调用；其他支持 SKILL.md 的智能体按自己的技能安装说明使用。

两个技能独立可用；需要时先对标，再蒸馏。分享包没有私人账号、密钥、登录数据、博主原视频和私有飞书表。

## 对标分析的用法、流程与功能

示例：
> 使用 $laolian-douyin-benchmark 分析这个抖音博主最近100条可见作品，找出相对日常表现突出的作品，对比普通作品，并分析他的产品与获客路径。主页：【填写链接】。

流程：核实账号与范围 → 采集公开数据和证据 → 同账号基线比较 → 突出与普通作品内容对照 → 核实商业入口 → 输出数据、报告与复用建议。

功能：单博主研究、多博主分别研究与比较、去重统计、缺失数据处理、中位数与相对倍数、爆款候选筛选、题材与结构对照、公开商业路径分析。

附带离线统计脚本；浏览器采集与内容判断由智能体和宿主工具执行。

## 蒸馏博主的用法、流程与功能

示例：
> 使用 $laolian-douyin-distill 下载并蒸馏这个博主最近100条作品，全量转写并逐条分析，提炼选题、标题、开头、文案结构及转化方法。主页：【填写链接】。

流程：核实账号与作品范围 → 建立清单 → 慢速串行下载与校验 → 带时间戳全文转写 → 逐条编码与必要画面核验 → 蒸馏规律、反例和模板 → 验收完成率。

功能：指定数量/时期/全部可见范围、断点恢复、视频有效性校验、全文转写、无口播待核验标记、逐条拆解、账号方法归纳、标题与开头模板、文案结构与转化模板、证据索引。

附带媒体辅助脚本；下载依赖 yt-dlp、ffprobe；本地转写另需 faster-whisper 和现有Whisper模型。脚本不自动安装依赖或下载模型。已有本地视频可以只做本地校验和转写。

## 分享时说明的能力边界

- 这是带工具辅助的智能体工作流；自动采集需要宿主提供可用浏览器，下载还受平台当前解析能力和访问限制影响，不保证任意账号都能抓全。
- 公开互动不是后台播放、完播或成交数据；分析提出有证据的解释与待验证假设，不证明爆款因果或真实收入。
- “全部可见作品”与“账号全部历史”不同，删除、私密或受限部分保留缺口。
- 全文转写不等于完整画面分析；报告分别列出下载、转写、逐条内容分析和画面核验数量。
- 资料用于研究；分享技能不附他人原视频，复用模板保留出处，不把原口播直接当原创发布。

## 建议的现场演示

先用一个小账号或已有10条清单展示对标报告，再用3条本地视频展示转写和方法模板。现场100条长任务可展示已完成结果与清单，平台受限时明确展示断点与缺口，不把历史成果说成现场完成。
